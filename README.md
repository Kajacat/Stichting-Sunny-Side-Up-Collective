# Stichting Sunny Side Up Collective

Website van Stichting Sunny Side Up Collective (Rotterdam). Eén statisch bestand: `index.html`.

Live via GitHub Pages: https://kajacat.github.io/stichting-sunny-side-up-collective/

## Aanpassen
Bewerk `index.html` (e-mailadres staat bovenaan het script, teksten staan in de HTML en in het `EN`-woordenboek). Commit naar `main`; de site wordt vanzelf bijgewerkt.
